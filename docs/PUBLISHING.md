## 隐私清理

- 原生 STRM 默认目录按当前用户主目录计算；Emby 钥匙串账号回退使用当前用户名称，不再包含作者机器用户名。
- 旧 LaunchAgent plist 是明确标注的示例模板，安装时应使用 `scripts/start.sh` 按实际路径生成。
- 文档、页面与测试中的个人域名改为保留示例域名，私人绝对路径改为明确示例。正常作者署名与应用命名空间保留。
- 初始隐私清理移除一张含个人目录的截图。后续复查又移除包含旧来源界面或个人域名示例的设置截图；保留图片经过本地查看及常见文本/EXIF 元数据检查。本次候选采用新的无父节点初始提交，旧截图和先前公开提交不进入当前分支祖先；私有备份保留原版。GitHub 的旧 SHA、缓存以及他人副本需要另行核验，不能仅凭分支替换就宣称已彻底消失。
- 历史验收文档中的生产任务/索引状态、具体备份文件名已移除，保留技术说明与测试方法。
- 网页测试样本中残留的请求验证字段改为固定假值，不使用捕获的验证内容。
- 发布文件列表与常见秘密形态检查没有发现 `.env`、真实数据库、Cookie 导出、登录会话、私钥或日志。此类启发式检查不能保证发现所有秘密；本次没有读取真实钥匙串、业务数据库或账号配置。

## 部署方案与必要适配

[Mac 小白教程](DEPLOYMENT.md) 使用原生 Keychain 与 launchd；[Docker 三应用教程](DOCKER.md) 使用 MediaLink、OpenList、Emby 与四个持久化命名卷。容器没有默认密码，默认只发布本机回环端口，115 授权与挂载、Emby 媒体库仍需用户自行配置。

Docker 相关代码与权限设计：

- 原生默认仍是 Keychain；仅显式设置 `MEDIALINK_VAULT_BACKEND=file` 才启用文件后端。环境变量提供容器默认设置，已保存配置优先。
- 文件凭据使用 Fernet 密文、0700 目录与 0600 文件、文件锁、原子替换及 fsync；拒绝凭据文件符号链接，文件损坏或密文/主密钥缺失时停止。主密钥与密文同卷，整卷或备份泄露时可被解密，必须整体保护。
- CLI 通过交互输入初始化密码并拒绝覆盖。容器关闭网页初始化；原生本机检查、登录、Cookie 和 Origin 保护没有放宽。没有迁移真实凭据。
- MediaLink 只读共享 OpenList 整个数据库目录及 WAL/SHM，使用规范化的 `mode=ro` SQLite URI，不使用 `immutable=1`；STRM 只读共享给 MediaLink 与 Emby。
- 生产安装不包含交互浏览器与抓取会话；Playwright 仅保留在开发依赖中，用于其他功能的隔离浏览器回归。没有使用 privileged、host 网络或 Docker socket。
- `.dockerignore` 采用构建输入允许列表，并排除真实数据、凭据、缓存、浏览器会话、图片与备份。
