# MediaLink 使用与接口说明

本页保留项目原有的详细功能、行为与 API 说明；其中钥匙串说明针对 Mac 原生安装，容器差异见 [Docker 教程](DOCKER.md)。首次安装请阅读 [小白部署教程](DEPLOYMENT.md)，项目入口见 [README](../README.md)。网站可用性与账号权限会影响实际结果；历史开发记录中的测试数量不代表当前版本的验收承诺。

## 搜索偏好与访问密码

“设置”按搜索偏好、服务连接、目录与网络、安全与访问分为四类页签。切换页签会保留当前草稿；各组独立保存，保存一组不会提交其他组的未保存修改。离开设置页面或刷新前请保存需要保留的修改。登录和连接检测使用已保存配置，不会自动保存网站地址或代理草稿。

在“搜索偏好”选择启用的来源，保存后普通资源搜索和影片详情只显示这些来源，并默认全部勾选。搜索时可临时取消来源；临时选择不改变保存的偏好。网站地址配置在同一页签中展开，代理统一在“目录与网络”中保存。允许关闭全部来源；此时资源搜索显示设置入口，影视资料浏览、手动粘贴入库、后台频道同步以及已有登录会话继续保留。

“普通搜索默认开启 TMDB 片名辅助”决定新进入普通搜索时的默认值，可在每次搜索中临时调整。影片详情始终使用已选影片的资料生成查询词。新安装或升级时缺少这些配置，默认启用四个来源并开启辅助；偏好保存在 SQLite，电脑和手机共享，重启后保留。其他设备刷新或重新进入应用后读取新偏好；使用旧页面提交已经停用的来源会收到刷新提示。

在“安全与访问 → 修改访问密码”填写当前密码、新密码及确认密码。新密码为 8–200 个字符，且不能与当前密码相同。成功后当前设备和其他设备的登录会话全部失效，正在打开的资源搜索连接也会结束，请使用新密码重新登录。当前密码错误不会退出登录；登录和改密校验共享每分钟最多五次的尝试限制。密码哈希继续保存在 macOS Keychain，不写入 SQLite 设置或浏览器存储。

`GET/PATCH /api/v1/settings` 提供 `enabled_search_sources: string[]`（允许为空、按 ID 去重）和 `default_use_tmdb: boolean`。`POST /api/v1/search` 省略或传 `null` 时读取保存值，显式传入空来源或停用／未知来源返回 422。搜索 SSE 新增 `auth_required` 事件，表示当前登录会话已失效。

运行设置浏览器回归：在 `frontend` 执行 `npm run build -- --outDir /tmp/medialink-settings-preview`，然后在项目根目录执行 `MEDIALINK_TEST_FRONTEND_DIST=/tmp/medialink-settings-preview MEDIALINK_BROWSER_TESTS=1 .venv/bin/pytest -q tests/test_settings_browser.py`。测试使用临时数据库、内存凭据和模拟来源，不访问生产账号或运行入库工作线程。独立构建目录用于验证；运行中的服务直接读取 `frontend/dist`，向该目录构建会更新正在提供的页面，正式发布时需同时重启后端以启用新接口。

## 影视发现与片名辅助

登录默认打开“发现 → 首页”：最近收录了资源的电影、剧集和动漫，各 12 部，加上 3 部轮播；手机显示双列海报，图片懒加载，缺失图片使用占位。点击海报进入资料详情，下方自动聚合搜索资源；剧集可选择整剧或某一季。入库按钮继续使用保存位置、分享预览和原有任务流程。

### 首页最近更新

首页由 MediaLink 聚合以下独立来源，需要先配置 TMDB 凭据；没有匹配资源时显示空状态：

- **Telegram 115 频道**：已同步的启用频道近 14 天消息，解析首行 `🎬/📺 片名 (年份)`、`S01E16`、`第1季 更新至第7集`、`全18集`、画质和 `{tmdbid-N}`，广告等其他格式忽略；每条 115 分享计一次网盘资源。
- **YTS**（`yts_url`，默认 `https://yts.gg`）：最新上架电影的前 4 页，带 IMDb 编号与评分。
- **EZTV**（`eztv_url`，默认 `https://eztvx.to`）：最新剧集种子前 3 页，带剧集 IMDb 编号。
- **蜜柑计划**：当季番表中最近更新的番剧，读取其 RSS 计算近 14 天的磁力数（6 小时内未再更新的番剧不重复读取）。

YTS、EZTV 和蜜柑的种子按 infohash 记入 SQLite `home_releases` 表，滚动保留 14 天，因此每次只需读取最新几页。条目按 IMDb 编号（TMDB `/find`）、`tmdbid` 或片名与年份关联 TMDB，再合并同一影片的磁力与网盘数。筛选规则：电影近三年上映、剧集近三年仍在播；TMDB 评分人数达到 20 时要求 6 分以上；隐藏只有枪版（CAM／TS／TC）和新闻、真人秀、肥皂剧、脱口秀类剧集；TMDB 热度下限对频道条目为 3（TMDB 低估国产片），对只在 YTS、EZTV、蜜柑出现的条目为 20，且 EZTV 上开播多年的剧集需至少 100 人评分。关联前先粗筛：YTS IMDb 低于 6 分、EZTV 只有一个种子、频道中三年前且无季集号的旧片转发都不查询 TMDB。动画类型且日本、中国或韩国出品的归入动漫。

每栏按资源更新日期倒序，同一天内有 115 分享的排前（可直接转存，磁力需离线下载），再按时间；轮播取 7 天内最热门、有背景图的 3 部，电影优先。卡片显示磁力数、115 数、最高画质（含杜比视界 DV）、TMDB 评分、YTS 来源的 IMDb 评分、TMDB 评分人数（100 人以上）和剧集进度。首页缓存 30 分钟，后台定时刷新；单个来源失败时显示“部分来源暂时不可用”并保留其他来源，全部失败时继续显示旧内容。首次整理需逐部查询 TMDB，约需数分钟，之后主要命中缓存（实测约 12 秒）。国产内容覆盖取决于已添加的 Telegram 频道，可多加几个 115 频道。

“发现 → 分类浏览”检索整个 TMDB 电影／剧集库，按热度排序。分行标签支持类型、年代、出品地区及原始语言；类型可多选包含（必须同时满足）或排除（命中任一即过滤），同一类型不会同时包含与排除。切换电影／剧集会保留通用条件并清除不适用类型；“一键重置”清空条件。年代支持近两年、本年起最近十个单年、十年区间、更早，以及自定起止年份（1000–9999）；电影按首次上映、剧集按首播筛选。“近两年”指本年与上一自然年，手机长列表通过“更多”展开。地区是出品国家／地区，语言是影片原始语言，不代表资源配音。零命中和访问失败分别显示空结果与重试提示。

分类接口：`GET /api/v1/tmdb/filters?media_type=movie|tv` 返回标准选项，`GET /api/v1/tmdb/discover` 接受 `media_type`、逗号分隔的 `include_genres`／`exclude_genres`、`year_from`／`year_to`、`country`、`original_language` 与 `page`。条件组合交给 TMDB 上游检索；类型包含用逗号交集，排除命中任一类型，结果使用现有海报结构。选项缓存 24 小时，分类结果缓存 30 分钟，所有条件和页码参与缓存键，复用现有 SQLite 缓存表。[电影分类接口](https://developer.themoviedb.org/reference/discover-movie)、[剧集分类接口](https://developer.themoviedb.org/reference/discover-tv)。

页面地址可复制、直接打开与刷新，例如 `/#/discover`、`/#/search`、`/#/media/movie/157336`、`/#/media/tv/66732`。在同一页面会话中返回海报墙会恢复筛选、已加载页和滚动位置；切换影片或离开详情会关闭旧 SSE 订阅并忽略过期响应。

普通关键词会立即开始原词搜索，同时查询 TMDB 影视候选。仅规范化后片名完全相同、年份符合且候选唯一时自动识别；同名不同年份、电影／剧集同名、模糊命中或候选分页未读完时请手动选择。支持“更换影片”和“仅搜原词”。TMDB 未配置、识别失败或超时不会阻断原词搜索。

识别后使用原词、中文译名、英文译名、原名，规范化去重后最多四词；不自行翻译，也不把非英语原名当作英文译名。选季生成中文数字季名、阿拉伯数字季名和 `S02` 等词。不同来源并行，同来源按现有访问限制串行查询，每请求 18 秒、来源整体 60 秒；识别等待最多 8 秒。资源分批返回，某个查询失败或超时仍保留已有结果。空结果提示等待该来源所有查询结束。

去重继续使用磁力 infohash 和 115 分享标识，并保留多个来源和命中词。普通搜索和详情资源统一按清晰度降序：**8K → 4K／2160P → 1080P → 1080I → 720P → 480P → 未知**，4K 与 2160P 同档；同档按 TMDB 片名、年份与季数匹配分数排列，同分保持原顺序。高清资源即使标为“待核对”也排在低清晰度已匹配资源前；信息不足或冲突继续保留说明。分批到达的高清资源自动上移，搜索结束时维持同档同分的现有顺序，类型／清晰度／来源筛选不改变排序。TMDB 资料与匹配优先级不保证资源实际内容，提交前仍需核对版本。没有中文简介时显示英文并标明。

热门缓存 30 分钟、片名查询 10 分钟、详情与译名 24 小时，持久化于 SQLite 的增量缓存表；上游限流遵守 `Retry-After`，网络错误／限流时可显示旧缓存与更新时间。海报只经要求应用登录的固定 TMDB 图片代理加载，缓存位于数据库同级 `tmdb-images`，最多 256 MB，按最近使用清理。

资料来源：[TMDB](https://www.themoviedb.org)。应用“关于影视资料”使用 [TMDB 官方标识](https://www.themoviedb.org/about/logos-attribution)，并展示：**This product uses the TMDB API but is not endorsed or certified by TMDB.**

## 每日番剧与追番订阅

“发现 → 每日番剧”读取 [蜜柑计划](https://mikanani.me) 当季番表，按周一至周日、剧场版、OVA 分组，默认打开今天，可切换往季。每部番剧显示最近更新日期；已关联 TMDB 的点开进入资料详情，否则用片名搜索资源。番表缓存 6 小时，访问失败时显示旧缓存与更新时间；TMDB 链接在后台按片名、年份匹配（复用首页的匹配规则）。海报经要求登录的 `/api/v1/anime/images/` 代理加载，缓存于数据库同级 `mikan-images`，最多 128 MB。番表、番剧页与 RSS 请求全局串行、间隔至少 3 秒，海报最多 4 个并发，均走应用代理；地址可在“设置 → 服务连接 → 网站地址配置”改为镜像。

点击“订阅”选择字幕组（或全部字幕组）、清晰度（默认 1080P）、必须包含／排除的关键词，确认 TMDB 剧集与季数和入库分类目录（默认“番剧默认入库目录”，留空用上次目录），并决定是否补齐已播出集数（默认补齐）。订阅后立即检查一次，之后每 30 分钟读取该番剧／字幕组的 RSS：每集只按规则挑一个版本（同集优先所选清晰度，再取最新发布），跳过合集与集数范围，自动创建勾选“自动规范命名”的入库任务，下载后去广告、按 TMDB 命名并放入 `分类目录/中文名 (年份) [tmdbid=ID]/Season NN/`，再同步 STRM 并通知 Emby。每集只会提交一次（v2 等后续版本不会重复入库）；不补齐时，订阅时已有的集记为“已跳过”。检查失败会记录原因并退避（15 分钟起，最长 6 小时）。

“追番订阅”页列出订阅、各集状态（入库中／已入库／需要处理／已跳过，点开进入任务详情）、上次与下次检查时间，可立即检查、编辑规则或目录、暂停／继续、取消订阅。取消订阅保留已创建的任务和媒体库文件。入库任务卡片显示“追番 · 第 N 集”。集数无法确定或 TMDB 集数不符时任务停在“需要处理”，与手动入库相同。

## 使用与失败处理

- 搜索结果逐来源返回，单来源失败不会阻塞其他来源。Knaben 使用无需密钥的公开 v2 接口，每次最多返回 50 条电影／剧集资源，并过滤标记为 1337x 的来源。LimeTorrents 读取首个搜索页中前 20 条影视详情，忽略广告链接，并发最多 3 个；有效详情先保留，全部不可读时单独报错。Nyaa 使用第一页结果，Telegram 返回最多 200 条匹配消息中的资源。
- Nyaa 的明确零命中页面按成功空列表处理，缓存 120 秒；识别搜索表单、空结果标题和零条统计，不再因缺少结果表格报错。空白响应、未知页面及网络失败仍单独提示；TMDB 的后续片名查询与其他来源继续搜索。
- LimeTorrents 明确的空结果页会显示“未找到匹配资源，可尝试英文片名”，并缓存 120 秒。真实人机验证、页面结构变化、网络失败及详情缺少有效磁力分别提示；普通 Cloudflare 脚本不会触发验证报错。搜索页或详情页真正要求验证时，可暂时取消勾选该来源，其他来源继续搜索；当前不接入浏览器验证会话。
- 网站单请求超时 18 秒、单来源总时限 60 秒，查询缓存 120 秒；可在设置中调整网站地址和代理。未使用 TMDB 辅助时使用原始关键词，海外网站可尝试英文片名。网页显示已索引消息数、最后更新和回溯状态，频道搜索仅覆盖已索引的可访问消息。
- 磁力按标准化 BTIH 去重，115 分享按分享标识去重，不按影视标题合并版本。手动粘贴资源也可入库。
- 磁力入库弹窗在后台解析文件目录树，展示路径、大小、已选数量与大小，并标出广告、样片、花絮和非影视文件；默认只勾选推荐的正片和字幕。支持逐文件／目录选择、全选、清空及“推荐选择”；解析成功后至少选择一个视频才能提交。**解析不阻塞提交**：中文转发资源的种子多数无法从 BT 网络取得元数据，可直接确认入库，115 下载完成后按实际文件自动筛选。预览使用本机 libtorrent 2.1.1 的元数据模式，不下载影视内容或提交 115 下载；成功结果缓存 24 小时，同一磁力复用解析，失败可重试。
- 规范入库（见下文）只把保留的文件逐个移入媒体库，不经过中转目录。关闭自动规范命名时：确认后仍由 OpenList 将磁力整包下载至任务暂存目录，完成核对后，仅将勾选文件按原目录层级逐文件整理至独立的 `<任务ID>-selected` 暂存目录，再进入原入库流程。未勾选内容保留在原下载暂存目录，不移动至媒体库、不删除。启用规范命名时仅处理勾选文件；任务详情显示选中／保留数量及下载暂存路径。移动操作的响应等待为 120 秒，其他 OpenList 请求仍为 25 秒。移动响应不确定时先核对源、目标、大小及可用文件身份，无法确认时暂停，不自动重复移动或覆盖。暂停后可点击“重试当前阶段”：已移动且核对通过的文件直接继续；不确定操作已等待至少 180 秒、源文件身份和大小一致且目标无同名文件时，才允许重新移动。身份缺失或内容冲突时继续暂停。
- 默认转存整份 115 分享，可预览并选择顶层文件／目录。缺少提取码时填写后再提交。
- 按“资源标识 + 目标目录”防止重复提交；磁力文件选择相同则返回已有任务，不同则提示冲突，请查看已有任务或更换目录，暂不支持对已完成任务补选文件。重启后恢复任务，提交结果不确定时只核对远端，不再次提交。无法关联自己的任务会要求检查，不会认领其他助手创建的任务。
- OpenList 离线任务状态异常时，使用已有 115 Open 授权只读核对原生下载状态；必须同时匹配资源 infohash 与本任务 UUID 暂存目录。文件总大小核对完成后才移动。
- 保存位置选择器支持新建文件夹、重命名子文件夹或当前文件夹。新建后自动选为保存位置，重命名后更新已选路径；同名文件／文件夹不覆盖，媒体根目录及活动任务使用的目录不能重命名。
- 入库弹窗的“自动规范命名”每次打开**默认勾选**，需关联 TMDB 影片后才能提交；取消勾选则保留原文件名和目录层级整包入库。勾选时“入库目录”改为**分类目录**（如 `电影/欧美电影`），应用在其中创建 Emby 标准的标题文件夹，弹窗显示将创建的名称；所选目录名与片名相同时提示会多嵌套一层：

  ```
  电影/欧美电影/谍影重重 (2002) [tmdbid=2501]/The Bourne Identity (2002) - 2160P.mkv
  电视剧/日韩电视剧/中头奖还是要上班 (2024) [tmdbid=…]/Season 01/中头奖还是要上班 S01E01.mkv
  ```

  标题文件夹为 `TMDB 中文名 (年份) [tmdbid=ID]`（无中文名时用原名，缺年份时省略），`tmdbid` 让 Emby 精确匹配；发布组外层目录被去掉。电影文件为 `原语片名 (年份) - 清晰度.扩展名`，剧集放入 `Season NN`，命名为 `中文名 S01E01.扩展名`，特别篇／OVA 放入 `Season 00`。电影将 `4K` 统一为 `2160P`、`8K` 为 `4320P`，保留 `1080I`；扩展名保持原样。已存在的标题文件夹（例如补入新一季）直接并入，同名文件暂停且不覆盖。
- **自动筛选**以 115 下载后的实际文件为准：文件名含网址或推广语（`www.`、`更多…请访问`、`无水印` 等）且体积不足正片 30% 的视频判为广告；`sample`、预告、`NCOP/NCED`、`PV`、`CM`、`Menu`、`YOKOKU`，以及 `Extras/SPs/特典` 等目录中的视频判为花絮／特典；体积远小于正片的视频判为样片；`.txt/.url/.png/.nfo/.zip` 等非影视文件和无法对应视频的字幕也不入库。站点前缀但体积正常的正片会保留并提示。排除的文件留在下载暂存目录，不删除；任务详情列出每个排除文件及原因，可逐项“改为入库”，也可把保留文件“排除”。下载前在弹窗中调整的勾选只作为保留／排除依据。
- 电影清晰度按人工逐文件修正、文件名、最近父目录、资源标注依次确定。剧集识别明确的 `S01E01`、`1x01`、中文季集格式，以及字幕组常见的 `[05]`、`[02v2]`、` - 11 `、`Episode 7`、`OVA_03`／`SP2`（第 0 季）；`1920x1080`、`[1080p]`、年份和 CRC 不会当作季集号。缺季时使用所选季数，TMDB 只有一个正片季时默认该季；不按文件排序推测集号。规范命名任务会按 TMDB 各季集数校验：季不存在或集号超出时暂停；非显式 `SxxEyy` 的绝对集号（如第 2 季目录中的 13–24）按前几季集数换算。人工填写的值不受校验限制。明确对应的视频字幕同步改名，保留语言、forced、SDH 等必要后缀；其他附件和关联不明确的字幕保留原名并提示。
- 启用自动规范命名后，未关联 TMDB、清晰度／季集号缺失或冲突时，文件保留在暂存目录，任务暂停。可在入库弹窗关联影片，或在任务详情查看原路径与新路径、识别依据并补全信息；仅用规则命名时，有效修正保存后继续整理；未在入库弹窗提前确认方案的模型任务需保存预览，再在任务详情确认后继续。一个任务对应一部电影或一部剧集，混合合集需拆分入库。多集合并文件必须人工处理，不接受用单集号掩盖多集；同目录不同版本生成同名文件时也暂停。
- 在“设置 → 服务连接 → 大模型辅助命名”配置通用 OpenAI 兼容 Base URL、模型 ID 和 API Key，再启用辅助命名。Base URL 保留 `/compatible-mode/v1` 等路径前缀，不包含 `/chat/completions`。密钥存入 Keychain，输入留空保留，清除会关闭辅助命名。默认直连，可单独选择使用应用代理；检测发送固定的小型命名样例，使用已保存配置。
- 大模型仅补全规则无法识别的清晰度、季号或集号，不替代 TMDB，不修改明确规则值或人工修正。每批最多 50 个视频，单次请求 60 秒超时；只发送相对文件路径、TMDB 快照、所选季数及已有解析结果，不发送文件内容、分享链接或账号凭据。规范入库任务中，模型补全的结果通过 TMDB 校验且无冲突时自动继续入库，校验不过才暂停；旧任务仍须在任务详情核对并点击“确认并重命名”。在任务详情手动保存修改后仍需确认；普通重试、刷新和重启不会跳过确认。模型请求附带 TMDB 各季集数，用于换算绝对集号。失败可人工补全或“重新识别”，不自动反复请求；失败批次保留此前校验通过的结果。
- 暂存名称冲突不覆盖、不自动追加序号；目标目录同名冲突可在任务详情更换媒体子目录再继续。每次改名先保存操作记录，再执行并核对；改名开始后计划锁定。响应超时或重启先核对源、目标和可用文件身份，不重复提交不确定的改名。远端没有可核对身份且响应不确定时暂停，需检查暂存文件。全部文件核对完成后才移动、同步 STRM 和通知 Emby。
- 入库弹窗勾选“自动规范命名”并关联 TMDB 后，可以点击“大模型规范命名”，先读取磁力勾选文件或只读展开所选分享目录，按规则识别并用模型补全缺失字段。展示原名、规范名、依据，允许逐文件修正和重新识别；分析中、识别失败、有错误或修改未保存时不能确认预览入库。没有可读清单时可继续原有流程。预览不会创建下载任务、转存或改名。
- 最终“确认入库”同时确认当前方案。下载后核对完整文件路径及大小，兼容磁力根目录保留或省略，映射建议、人工修正与文件身份；规范名称一致后自动完成命名、STRM 和 Emby，不重复调用模型或要求确认。清单、映射、名称或冲突变化时转到任务详情核对。关闭弹窗会取消预览，资源、选择、TMDB、季数或清晰度变化会清除旧方案，迟到响应被丢弃。可信草稿在最后活动 30 分钟后过期。
- 模型请求使用 JSON 输出模式，仅在服务明确拒绝 `response_format` 时兼容重试一次。接受完整 JSON 的单层代码围栏、整数数字字符串、清晰度别名与大小写、空字段及一致的已知字段回显；仍拒绝重复 JSON 键、未知／重复文件 ID、布尔或越界数字、冲突字段和生成的路径。错误提示区分 JSON、字段、ID、冲突、截断及拒绝，不保存或展示原始响应。
- 既有任务继续原始命名流程，已完成的媒体不会批量改名。
- 等待对应 STRM 文件生成后通知 Emby。显示“已入库，已通知 Emby”表示 Emby 接受了刷新请求，实际刮削由 Emby 的现有配置完成。
- 网络失败按退避延迟重试当前阶段，账号、权限、目录冲突等需要处理后点击重试。Emby 失败不会重新下载或转存。
- 取消停止本地流程，并在已知远端离线任务编号时请求取消；保留所有已生成文件。提交结果不确定时需要在 115 / OpenList 核查远端任务。已取消任务不自动重新提交。
- 应用不会自动清理任何 115 文件或暂存内容。需要清理时可核对任务 UUID 后手动处理。

## API

所有业务 API 要求登录 Cookie，写操作检查同源 Origin。认证入口 `/api/v1/auth/state`、`/setup`、`/login`，首次设置限本机。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/sources` | 完整搜索源 `{id,name,kind}` 目录，包含停用来源 |
| `POST /api/v1/auth/password` | `{current_password,new_password}`，验证当前密码并修改；成功后所有设备重新登录 |
| `POST /api/v1/search` | `{query,sources?,use_tmdb?,media?:{type,id,season_number?}}`；省略来源和辅助开关时读取保存的搜索偏好，只允许启用来源的非空子集；返回搜索 ID |
| `GET /api/v1/search/{id}/events` | SSE `metadata`、`result`、`done`、`expired`；搜索 10 分钟过期 |
| `GET /api/v1/home` | 首页 `{source,status,message,error,warnings,updated,refreshing,stale,featured,sections}`；`source` 固定为 `local` |
| `POST /api/v1/home/refresh` | 立即重新整理当前来源的首页 |
| `GET /api/v1/tmdb/trending` | `media_type=all/movie/tv`、`window=day/week`、`page` |
| `GET /api/v1/tmdb/search` | `query`、`page`；影视候选，排除人物 |
| `GET /api/v1/tmdb/{media_type}/{id}` | 电影／剧集详情、译名、演职员和季列表 |
| `GET /api/v1/tmdb/images/{size}/{path}` | 登录后加载图片，固定上游与尺寸白名单，仅接受单层安全图片路径 |
| `GET /api/v1/tmdb/check` | 重新请求上游验证凭据，不以旧缓存代替检测 |
| `GET/POST /api/v1/tasks` | 查询任务／提交 `{link,title,target,password?,selected_ids?,sources?}` |
| `GET /api/v1/tasks/{id}` | 当前阶段与事件记录 |
| `GET /api/v1/anime/schedule?year=&season=` | 蜜柑计划番表（`season` 为 冬／春／夏／秋，省略为当季），每项含 `media` 与 `subscribed`；`POST /api/v1/anime/schedule/refresh` 强制刷新 |
| `GET /api/v1/anime/bangumi/{id}` | 番剧资料、字幕组及近期发布、建议的 TMDB 关联与季数、默认入库目录 |
| `GET/POST /api/v1/subscriptions` | 查询订阅（含各集任务状态）／创建 `{bangumi_id,subgroup_id?,media:{type,id,season_number},target,rules:{resolution?,include?,exclude?},backfill}`，创建后立即检查；同一番剧与字幕组重复订阅返回 409 |
| `GET/PATCH/DELETE /api/v1/subscriptions/{id}` | 查看／修改 `enabled`、`rules`、`target`／取消订阅（保留任务与文件）；`POST /api/v1/subscriptions/{id}/check` 立即检查 |
| `POST /api/v1/tasks/{id}/retry` | 重试当前阶段；冲突阶段可传 `{target}` |
| `POST /api/v1/tasks/{id}/cancel` | 停止本地流程，保留文件 |
| `POST /api/v1/shares/preview` | `{link,password?}`，分页读取全部顶层内容 |
| `GET/POST /api/v1/channels` | 查询含 `mode,last_synced`；添加 `{peer,mode?}`，默认 `public_web`，可选 `api` |
| `PATCH/DELETE /api/v1/channels/{id}` | `{enabled}` 暂停恢复／移除索引 |
| `GET/PATCH /api/v1/settings` | 查询／保存配置，敏感字段仅写入 Keychain |
| `GET /api/v1/settings/check` | 检查服务、公开网页及可选 Telegram API 连接 |
| `GET/POST /api/v1/directories` | 浏览媒体目录／创建子目录 `{parent,name}` |
| `PATCH /api/v1/directories` | 重命名文件夹 `{path,name}` |
| `POST /api/v1/magnets/preview` | `{link}` 返回 `{preview_id,infohash,root,files:[{id,path,size,kind,role,keep,reason}],total_size}`；`role` 为 video／subtitle／ad／extra／sample／other，`keep` 为推荐勾选；仅解析元数据，支持现有 BTIH 格式，不依赖 115 Cookie |
| `GET /api/v1/naming/layout?media_type=&media_id=` | 返回将创建的 Emby 标题文件夹名 `{folder}` |
| `POST /api/v1/tasks` | 可选 `magnet_selection:{preview_id,selected_ids}` 使用可信预览清单，过期返回 409、无效／空选择或未选择视频返回 422；省略或 null 表示整包入库。入库请求提供 `auto_naming:boolean`（默认 `false`）；仅为 `true` 时使用可选 `media:{type,id,season_number?}`、`resolution`，名称取自服务端 TMDB 资料，任务按规范入库流程处理，`target` 为分类目录，`magnet_selection` 只决定保留哪些文件；可选 `naming_preview:{preview_id,revision}` 同时确认当前方案，输入或已有任务方案不一致返回 409 |
| `POST /api/v1/naming/previews` | `{link,password?,selected_ids?,magnet_selection?,media,resolution?}` 创建异步只读命名预览，返回 `{preview_id,revision,status,error,naming}` |
| `GET/PATCH/DELETE /api/v1/naming/previews/{id}` | 轮询、保存 `{revision,files:[{id,resolution?,season_number?,episode_number?}]}`、取消草稿；过期或旧修订返回 409，不接受文件路径 |
| `POST /api/v1/naming/previews/{id}/analyze` | 手动重新识别，取消旧作业，迟到结果不能覆盖新修订 |
| `GET /api/v1/tasks/{id}/naming` | 返回命名预览、文件标识、识别依据、错误与警告、是否可编辑；未启用规范命名的任务返回 409 |
| `POST /api/v1/llm/check` | 使用已保存大模型配置检测兼容接口与字段解析能力 |
| `POST /api/v1/tasks/{id}/naming/analyze` | 可编辑的命名任务重新识别缺失字段；进行中复用当前作业 |
| `POST /api/v1/tasks/{id}/naming/confirm` | `{revision}` 确认当前无错误命名预览，旧修订返回 409；重复确认幂等 |
| `PATCH /api/v1/tasks/{id}/naming` | 修正 `media`、资源 `resolution` 或 `files:[{id,resolution?,season_number?,episode_number?,included?}]`；`included` 仅用于规范入库任务，改变文件保留／排除（非影视文件不可入库，null 恢复自动判断）；不接受路径修改，逐文件字段为 null 时清除人工修正；计划锁定后返回 409。命名结果增加 `folder`、逐文件 `destination`、`excluded` 与 `excluded_count` |

`PATCH /settings` 使用 `tmdb_credential: {type:"token"|"api_key",value}` 保存凭据，`tmdb_credential:null` 清除；响应只有 `tmdb_configured` 和 `tmdb_auth_type`。`metadata` SSE 返回识别状态、候选、服务端读取的影片和实际查询词；资源可选增加 `matched_queries` 与 `match: {status,score,explanation}`，已有 `result/done` 结构保持兼容。

`PATCH /settings` 另支持 `llm_enabled`、`llm_base_url`、`llm_model`、`llm_use_proxy` 和只写 `llm_api_key`。密钥 `null` 显式清除并关闭辅助命名，空字符串保留；设置响应返回 `llm_key_saved`、`llm_configured`，不返回密钥。命名预览增加 `revision`、`review_required`、`llm:{status,message}`，文件显示模型补全依据。
